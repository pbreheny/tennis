# Bayesian time series models of tennis data

## Model

(sketch)

* Models log-odds at set level
* Includes fixed effects for surface and an autoregressive, time-varying, effect for player skill

## Data sources

* Historical data from
  * https://github.com/JeffSackmann/tennis_atp
  * https://github.com/JeffSackmann/tennis_wta
* In-progress (current year) data from
  * http://www.tennis-data.co.uk/
* Tournament draw data from
  * https://www.tennisexplorer.com/matches/
